# Nasal Airflow Reconstruction · 鼻腔气流重构项目（CT → 三维建模 → CFD 气流分析）

> 「罕见·无界」黑客松赛题 · 项目2：空鼻症 + 鼻腔气流模拟分析工具
> 由空鼻症患者 Charlie 联合 [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)发起 · 患者共创 · 一个赛题 = 一个长期开源项目

把患者主观的通气不适，转化为**可以看见和比较的气流数据**。

> **本次黑客松范围声明**：只实现**阶段一**——患者上传匿名化鼻腔 CT 后，系统自动完成三维建模与 CFD 气流模拟，输出鼻腔气道 STL、气流可视化结果和基础分析。阶段二的模型修改与二次模拟、阶段三的个性化隐形鼻塞设计均为后续路线，**本次不开发、不演示、不作为交付物**。

## 🧭 项目背景

部分患者接受鼻甲、鼻中隔或鼻窦相关手术后，虽然影像和鼻内镜显示鼻腔已经通畅，但仍然会出现明显的通气不适：吸不到气、过度空旷、气流直冲、干燥、灼热、头闷、呼吸缺少自然反馈。这些不适可能与鼻腔结构改变、气流重新分布、黏膜热湿交换变化及感觉反馈异常有关——而传统 CT 和鼻内镜主要显示结构，**不能直接展示空气如何流动**，医生很难仅凭现有检查判断患者具体哪里不舒服。

有一位患者术后经历了半年类似空鼻症的严重通气不适，后来症状逐渐缓解，但留下了很深的心理创伤。这说明**术后通气不适需要被认真分析**，等待恢复期的患者也需要安全、可逆的支持方式。

**项目要解决的问题**：

- 把患者主观的通气不适转化为可以看见和比较的气流数据
- 减少鼻腔气流模拟对人工分割、模型修复和专业 CFD 操作的依赖
- 在手术或产品制作前，用数字模型验证不同结构调整可能带来的变化（后续阶段）
- 为个性化隐形鼻塞的设计、打印和试戴提供量化依据（后续阶段）

## 🗺 三阶段路线

| 阶段 | 核心任务 | 主要交付物 |
|---|---|---|
| **阶段一（本次实现）** | 自动生成患者原始鼻腔模型并完成 CFD 计算 | 基准气道 STL、气流图和基础分析结果 |
| **阶段二（后续规划）** | 增删改数字鼻腔结构并进行多轮二次模拟 | 本次不开发、不演示 |
| **阶段三（长期规划）** | 将推荐方案转化为可佩戴的隐形鼻塞 | 本次不设计鼻塞 STL、不制作样件 |

## 🛠 阶段一：气流模拟自动化

**输入要求**：原始 DICOM 文件（非胶片照片/截图）；CT 层厚 ≤1mm（推荐 0.5mm）；扫描范围完整覆盖鼻尖至鼻咽；推荐骨算法/高分辨率重建，平扫即可；上传前完成匿名化并按需裁剪面部区域或去识别。

**主要功能**：导入并检查匿名化 DICOM → 自动识别和分割鼻腔气道 → 排除外部空气、鼻窦及无关腔隙 → 保留完整鼻孔入口和鼻咽出口 → 生成三维模型 → 检查修复破洞、毛刺、异常网格 → 输出可用于 CFD 的气道 STL → 自动/半自动设置网格、出入口和壁面条件 → 完成 CFD 求解并检查收敛 → 展示速度、压力、流线、鼻阻力和壁面剪切应力。

**交付物**：鼻腔气道 STL 与可旋转三维模型、CFD 计算文件及网格质量记录、速度/压力/流线图、鼻阻力与壁面剪切应力等基础指标、患者和医生能理解的基础气流分析。

**阶段意义**：回答"患者当前的鼻腔气流是什么样"，气流过度集中、高速射流、低速区域或分布失衡可能出现在哪里。

```
CT影像 → 自动分割 → 三维重建 → 模型修复 → CFD计算 → 阶段一分析
```

> 注：本次只输出**鼻腔气道 STL**（空气可通过的空间，用于 CFD 计算）；**隐形鼻塞 STL** 是阶段三的未来产品模型，本次不设计、不输出。

## 📌 当前技术基础与进展

- **人工基准流程已跑通**（全开源工具链）：DICOM CT → 3D Slicer 气道分割 → Blender 模型修复 → SimScale/OpenFOAM CFD 计算 → ParaView 可视化；《鼻腔气流 CFD 模拟 SOP 2.0》已标准化全流程人工操作
- **概念验证完成**，正在推进多病例标准化复现；已有 3 例完整测试案例 + 1 例培训数据
- **CT 数据获取突破**：打通云影像链接直接提取 DCM 薄层文件，患者无需去医院用 U 盘拷贝；备有向医院申请薄层重建数据的标准化沟通模板
- 已积累数百例患者群体与病例资源，完成鼻瓣区气流阻力、Coanda 效应等理论梳理
- **当前工作重点**：把已跑通的人工流程标准化、自动化（降低人工分割 30–60 分钟/例的耗时与主观差异）

## 🔭 后续路线与应用拓展（本次不实施）

- **阶段二**：在原始模型上虚拟增删/调整局部结构并二次模拟，生成 3–5 个候选方案对比（气流均匀性、高速射流、鼻阻力、鼻窦开口影响等），服务术前方案研究与术后问题分析
- **阶段三**：两类隐形鼻塞设计（下鼻甲缺失型 / 中鼻甲缺失型），贴合面、导流通道、固定与安全取出结构、隐形外观与 3D 打印
- **应用场景**（阶段二能力）：鼻腔整形、功能性鼻整形、鼻炎/鼻阻塞相关手术的术前方案数字比较

## 👥 病友参与方式

病友不需要掌握 AI、CFD、CAD 或 3D 打印——最重要的作用是说明哪里不舒服、症状何时最明显、手术前后变化，以及使用棉片/临时鼻塞等方法后是否改善。后续阶段中，病友可判断虚拟方案是否符合真实不适位置，并反馈试戴体验。一个病友的经历不能代表所有病友，项目将逐步扩大病例与验证范围。

## ⚕️ 隐私和安全边界

- DICOM 数据上传前必须删除姓名、出生日期、病历号等个人信息；医学影像可能包含可识别面部轮廓，训练数据应裁剪至鼻腔区域或做面部去识别
- 黑客松成果属于**研究原型和临床辅助工具**，不能单独用于诊断、决定手术方案或鉴定医疗责任
- 任何实体鼻塞试戴都应经过耳鼻喉科医生评估；存在新鲜创面、活动性出血、感染或明显黏膜损伤时不应直接试戴；出现疼痛、出血、明显堵塞等异常应立即停止使用
