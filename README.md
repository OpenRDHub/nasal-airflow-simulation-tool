# Personalized Nasal Plug Design Tool · 个性化鼻塞一体化设计工具（鼻腔气流模拟分析）

> 项目2：空鼻症 + 鼻腔气流模拟分析工具 —— [OpenRD 罕见病开源社区](https://github.com/OpenRDHub)

为呼吸困难群体打造个性化鼻塞一体化设计工具。

## 真实处境

对一些空鼻症患者来说，连每天最本能的呼吸，都可能伴随着持续不适甚至痛苦。每个人鼻腔结构不同，真正合适的鼻塞目前仍很难做出来。

## 挑战方向

- 结合患者 CT 数据
- 完成从鼻腔三维重建、气流模拟分析到个性化鼻塞模型输出的全链路工具搭建
