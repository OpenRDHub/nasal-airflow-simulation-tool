# Personalized Nasal Airflow Simulation Tool · 个性化鼻塞一体化设计工具（鼻腔气流模拟分析）

> 「罕见·无界」黑客松赛题 · 项目2：空鼻症 + 鼻腔气流模拟分析工具
> 由空鼻症患者 Charlie 联合 [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)发起 · 患者共创 · 一个赛题 = 一个长期开源项目

打造**平民化、低成本**的鼻腔气流分析工具：输入患者鼻腔 CT / 鼻内镜影像，自动重建鼻腔三维模型并开展气流仿真，直观定位气流紊乱区域。

## 🧭 背景与真实处境

**疾病概述**：空鼻症（Empty Nose Syndrome，ENS）属于鼻甲过度切除手术诱发的结构性鼻炎。鼻腔解剖结构改变后，鼻腔内部气流严重紊乱，患者长期存在鼻腔异常干燥、窒息感、神经刺激等一系列严重症状；部分医务人员容易将这类器质性病变简单归类为心理问题，造成大量患者长期无法得到有效诊疗。

**现存临床痛点**：鼻腔填充、鼻腔结构重建等修复方案已证实能够缓解部分症状，但手术方案高度依赖医生个人经验——填充位置、角度、剂量缺少客观量化依据，手术效果难以提前预判，大量患者多次手术依旧无法改善。

**核心症结**：缺少手段量化鼻腔内部气流力学异常，无法直观展示气流紊乱位置。对一些空鼻症患者来说，连每天最本能的呼吸，都可能伴随着持续不适甚至痛苦；而每个人鼻腔结构不同，真正合适的鼻塞目前仍很难做出来。

## 🎯 项目目标

- 结合患者 CT 数据，完成**从鼻腔三维重建、气流模拟分析到个性化鼻塞模型输出的全链路工具搭建**
- 为鼻腔填充、结构重建手术提供客观数据支撑，改变手术"凭经验盲做"的现状，提升一次手术成功率
- 搭建沟通载体，让患者借助量化气流数据与临床医生高效、平等地沟通

## 🛠 技术路线

**人工基准工作流（已完成 SOP，全开源工具链）**：

```
CT 原始 DICOM → 3D Slicer 人工分割鼻腔气道 → Blender 修复三维模型
→ SimScale / OpenFOAM 流体仿真 → ParaView 气流可视化分析
```

作为基准金标准，可精确计算鼻腔内气流速度、压力、壁面剪切应力等关键指标；无需付费商业软件。短板：人工分割耗时 30–60 分钟/例，边界判断存在主观差异，难以批量处理。

**自动化目标（正在招募）**：患者上传 CT 原片（DCM），系统自动输出可直接进入 CFD 的鼻腔气道 STL 模型。不限定框架与网络结构，社区提供成对 DCM 数据与愿意配合验证的患者群体。

**当前瓶颈**：Blender 几何修复流程较繁琐（修复简化网格中的点线面问题）；算法开发前需要一份完整需求文档（需求说明 + 配套文件清单 + 各文件作用）。

## 👥 患者参与方式

**CT 资料前置检查清单**：源文件为 .dcm 原始影像（非截图）；层厚 ≤1mm（推荐 0.5mm）；扫描范围完整覆盖鼻腔、鼻咽；骨算法 / 高分辨率重建；平扫即可无需造影剂；提前规划隐私匿名化方案。

**隐私安全规范**：使用 3D Slicer Anonymize 工具清除个人信息；最优方案是直接上传分割后的 STL 几何模型（不携带隐私）；CT 可三维重建面部轮廓，训练数据建议裁剪至鼻腔 ROI 或做面部去识别（defacing）。

社区提供完整文字 SOP 手册、操作录屏视频、线上进度会议回放；可以志愿者或素材志愿者等身份参与。
