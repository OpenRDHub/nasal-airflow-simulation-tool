# ENS Nasal Airflow Reconstruction Tool · 空鼻症（ENS）鼻腔气流重构分析工具

> 「罕见·无界」黑客松 · 赛题2 · 空鼻症 + 鼻腔气流模拟分析工具
> 依据《空鼻症（ENS）鼻腔气流重构分析工具 产品需求书 V1.0》（2026-10-01）编写 · 由空鼻症患者 Charlie 联合 [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)发起

打造**平民化、低成本**的鼻腔气流分析工具：输入患者鼻腔 CT，自动重建鼻腔三维模型并开展气流仿真，直观定位气流紊乱区域；为鼻腔填充、结构重建手术提供客观数据支撑，改变手术「凭经验盲做」的现状，力求依靠数据提升一次手术成功率。同时搭建沟通载体，让患者借助量化气流数据与临床医生高效、平等地沟通。

> **本次黑客松范围：仅阶段一**——自动完成患者原始鼻腔的三维建模和 CFD 气流模拟，输出鼻腔气道 STL、气流可视化结果和基础分析。阶段二（模型修改与二次模拟）、阶段三（个性化隐形鼻塞）为后续路线，不开发、不演示、不作为交付物。

## 🧭 一、项目背景

**疾病概述**：空鼻症（Empty Nose Syndrome，ENS）属于鼻甲过度切除手术诱发的结构性鼻炎。鼻腔解剖结构改变后气流严重紊乱，患者长期存在鼻腔异常干燥、窒息感、神经刺激等症状；部分医务人员容易将其简单归类为心理问题，造成大量患者长期无法得到有效诊疗。

**现存临床痛点**：鼻腔填充、结构重建等修复方案已被证实能缓解部分症状，但手术方案高度依靠医生个人经验——填充位置、角度、剂量缺少客观量化依据，效果难以提前预判，大量患者多次手术依旧无法改善。**核心症结：缺少手段量化鼻腔内部气流力学异常，无法直观展示气流紊乱位置。**

**患者场景**：常见不适感受包括吸不到气、过度空旷、气流直冲、干燥、灼热、头闷、呼吸缺少自然反馈。传统 CT 和鼻内镜主要显示结构，不能直接展示空气如何流动。有一位患者术后经历半年严重通气不适、症状缓解后仍留下深层心理创伤——术后通气不适需要被认真分析，等待恢复期的患者也需要安全、可逆的支持方式。

**项目积累**：患者 Charlie 联合社区发起；数百例真实病例资源；典型案例验证（鼻中隔前端高位 0.1mm 膜性缺损，微创修复后症状显著缓解，证明气流可视化的临床价值）；国内鼻腔填充手术累计逾万例的有效性调研；第一阶段概念验证完成，已有 3 例完整测试案例 + 1 例培训数据；已打通云影像链接直接提取 DCM 文件（患者无需去医院拷盘）。

## 🎯 二、要解决的问题

1. 把患者主观的通气不适转化为可以看见和比较的气流数据
2. 减少鼻腔气流模拟对人工分割、模型修复和专业 CFD 操作的依赖
3. 在手术或产品制作前，用数字模型验证不同结构调整可能带来的变化（后续阶段）
4. 为个性化隐形鼻塞的设计、打印和试戴提供量化依据（后续阶段）

## 🛠 四、阶段一功能需求

**输入资料要求**：原始 DICOM 文件（非胶片照片/截图）；CT 层厚 ≤1mm（推荐 0.5mm）；扫描范围完整覆盖鼻尖至鼻咽；推荐骨算法/高分辨率重建、平扫即可；上传前完成匿名化并按需面部去识别（defacing）。

**主要功能清单**：导入并检查匿名化 DICOM → 自动识别分割鼻腔气道 → 排除外部空气、鼻窦及无关腔隙 → 保留完整鼻孔入口和鼻咽出口 → 生成三维模型 → 检查修复破洞/毛刺/异常网格/法向 → 输出可用于 CFD 的气道 STL → 自动/半自动设置网格、出入口和壁面条件 → 完成 CFD 求解并检查收敛 → 展示速度、压力、流线、鼻阻力和壁面剪切应力。

**关键技术参数**（来自人工 SOP，作为自动化验收基准）：

- 气道分割：空气 HU 值 −1024 至 −300（按实际微调）；鼻孔以外鼻孔最外缘平面为界；鼻咽出口沿冠状面切平整、位置统一为软腭游离缘水平；鼻窦/鼻泪管/咽鼓管开口一律排除；ENS 特别注意——下鼻甲切除后鼻腔异常宽大，阈值分割边界易错，残留凹陷瘢痕腔隙与主气道连通且有实际气流的计入，盲端排除
- 几何修复：简化面数 >3 万、缩减 30–50%（过低会产生点线面问题）；最终建议 3 万–10 万面；合并重复顶点、清退化边零面积面；法向统一向外；必检非流形与交叉面
- CFD 设置：不可压缩流、空气；入口静息呼吸约 15 L/min（双侧合计）或 Pressure inlet −18 Pa；出口 Pressure outlet = 0；壁面无滑移；鼻孔/鼻咽各加圆柱延长流体区域；雷诺数约 1000–2500（层流到过渡流）；入门 Laminar 跑通、定量推荐 k-omega SST；网格 30 万–200 万单元；云端计算约 1–4 小时

**输出指标**：

- 基础指标：气流速度图、压力分布图、流线图、**鼻阻力**（入口出口压差÷流量，临床衡量鼻腔通气功能的核心指标）、壁面剪切应力
- **ENS 专用分析指标**（比「气流快慢」更有意义）：气流分布均匀性（是否异常集中或大片低速区）；鼻甲区低速死区（原鼻甲所在区域速度过低——黏膜接触不到流动气流，与「感觉不到呼吸」主诉高度相关）；黏膜壁面剪切应力（气流感受器依赖机械刺激产生「通畅感」，过低→刺激不足→主观憋气感）；温湿度交换（进阶）

## 📌 五、当前技术基础

人工基准流程（金标准，全开源工具链）：`DICOM CT → 3D Slicer 分割 → Blender 修复 → SimScale/OpenFOAM 仿真 → ParaView 可视化`。

工具清单：3D Slicer / Blender / SimScale（免费社区版）/ ParaView / OpenFOAM——全部免费。人工耗时基线：熟练后分割 10 分钟、修复 30–60 分钟、求解 1–4 小时、可视化 30 分钟——**自动化要替代的正是这些人工环节**（支持批量处理、消除主观差异、全病例同一标注标准）。

## 👥 六、病友参与方式

病友不需要掌握 AI、CFD、CAD 或 3D 打印。最重要的作用：说明哪里不舒服、症状何时最明显、手术前后变化、用棉片/临时鼻塞等方法后是否改善。（阶段二/三）判断虚拟方案是否符合真实不适位置、反馈试戴体验。一个病友的经历不能代表所有病友，项目将逐步扩大病例与验证范围。

## 🤝 七、需要的技术支持

> 我们缺的不是想法，是能把想法变成代码的人。

- **AI / 医学影像方向技术志愿者**：搭建「输入 DCM → 输出 STL → 输出 CFD」的自动化流程。不规定框架或网络结构，由工程师自己判断迭代；项目提供成对 DCM 数据与愿意配合验证的患者
- **CFD 工程师**：验证 AI 输出的几何是否经得起流场考验

## 🔭 八、后续路线（本次不实现）

- **阶段二**：虚拟增删改局部结构+二次模拟，生成 3–5 个候选方案对比（气流均匀性、高速射流、鼻阻力、左右流量分配、鼻窦开口影响等），服务术前方案研究
- **阶段三**：个性化隐形鼻塞（下鼻甲缺失型 / 中鼻甲缺失型），贴合面与导流通道、固定与安全取出结构、隐形外观、3D 打印与试戴
- 应用拓展：鼻腔整形、功能性鼻整形、鼻炎/鼻阻塞手术的术前数字比较；长期研究方向：鼻腔气流与头晕、脑雾、睡眠质量等的关联（待验证）

## ⚕️ 九、隐私与安全边界

- DICOM 上传前必须删除姓名、出生日期、病历号；影像可能含可识别面部轮廓，训练数据裁剪至鼻腔区域或去识别；最优方案是直接上传分割后的 STL（纯几何，不含个人信息）
- 黑客松成果属于研究原型和临床辅助工具，**不能单独用于诊断、决定手术方案或鉴定医疗责任**；系统应作为医生的术前分析与决策辅助，不替代临床检查与医生判断
- 任何实体鼻塞试戴都应经过耳鼻喉科医生评估；有新鲜创面、活动性出血、感染或明显黏膜损伤时不应试戴；出现疼痛、出血、明显堵塞应立即停止
